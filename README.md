# Railway Salary Calculator PWA

## Publish free with GitHub Pages
1. Extract this ZIP on your computer.
2. Sign in at https://github.com and create a **public** repository named `railway-salary-calculator`.
3. Upload all files and the `icons` folder into the repository root (not inside another nested folder).
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for deployment. The site address will follow `https://YOUR-USERNAME.github.io/railway-salary-calculator/` (replace YOUR-USERNAME; this is an example, not a live link).
7. On Android, open that HTTPS address in Chrome, tap ⋮, then choose **Install app** or **Add to Home screen**.

## Files
- `index.html`: app screen and salary inputs
- `styles.css`: responsive design
- `app.js`: calculations, reset, copy and install prompt
- `manifest.webmanifest`: PWA metadata and icons
- `sw.js`: offline caching after first load
- `icons/`: app icons

Formula assumptions are as specified by the user; this is an estimate, not an official payroll tool. PWA install/offline features require HTTPS or localhost.
